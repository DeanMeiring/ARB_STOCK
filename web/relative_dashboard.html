This page tracks the cross-sectional model: instead of predicting whether a coin's price goes up in absolute terms, it predicts whether the coin will beat the basket's mean return over the next hour (market-wide moves cancelled out). It is not live in /predict or the Telegram bot yet — everything here (predictions, paper trades, P&L) is a separate, independent mock/paper-trading run so it can be evaluated before any decision to promote it. Same mechanics as the main dashboard's paper trading, just against this different target.
